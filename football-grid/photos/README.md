# Your own player photos

Put a photo here named after the player's Wikidata ID, e.g. `Q1234567.jpg` (or .png / .webp).
It replaces any photo from Wikidata or Wikipedia after the next "Update data" run.

Find a player's ID in `data/data.json` (first value of each player row), or on wikidata.org.
Square-ish photos with the face near the top work best. Only use photos you have the right to use.
